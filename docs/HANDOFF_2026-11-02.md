## Architecture in one paragraph

Canonical admission (Python eligibility → `CompletedSessionPolicy` → `ScreenerEvidence`
`SESSION_UNCONFIRMED`) is untouched and still refuses unproven sessions. A **separate
personal path** captures unproven sessions to `data/personal/bars/<YYYY>/<YYYY-MM-DD>.json`
(git-ignored), serves them read-only, and projects the same thirteen features through the
unchanged `TechnicalFeatures.Project`. Personal data is never canonical, never
`VERIFIED`, never affects soak, and is never mixed into a canonical table.
